## 🔄 آلية العمل الجديدة

### عند أول تشغيل:
1. المستخدم يرى صفحة البداية (Landing Page)
2. يختار "تسجيل مكتب جديد"
3. يدخل بيانات مكتبه الحقيقية:
   - اسم المكتب
   - رقم الرخصة
   - PIN المدير
   - بيانات الموظفين الأوليين
4. يبدأ استخدام التطبيق ببياناته الحقيقية

### عند تسجيل الدخول:
1. المستخدم يدخل PIN المدير أو الموظف
2. لا توجد تلميحات أو بيانات افتراضية
3. يجب أن يكون قد تم تعيين PIN مسبقاً

## ⚠️ ملاحظات هامة

### 1. البيانات القديمة:
إذا كان لديك بيانات من إصدار سابق، يمكنك:
- تصديرها كنسخة احتياطية (JSON)
- إعادة تعيين البيانات
- استعادة النسخة الاحتياطية

### 2. PINs الافتراضية:
لم يعد هناك PINs افتراضية. يجب:
- تعيين PIN للمدير عند إنشاء المكتب
- تعيين PIN لكل موظف
- حفظ PINs في مكان آمن

### 3. الإعدادات الافتراضية:
- العملة: ر.س (ريال سعودي)
- اللغة: عربي
- المظهر: فاتح
- باقي الإعدادات: فارغة
