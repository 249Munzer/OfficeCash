## 1. نظرة عامة على المشروع

### 1.1 الوصف
تطبيق سطح مكتب مستقل (Desktop Application) لإدارة الحركات المالية والمصروفات اليومية للمكاتب والشركات الصغيرة.

### 1.2 التحول التقني
- **الإصدار 1.0:** تطبيق ويب (React + Vite + localStorage)
- **الإصدار 2.0:** تطبيق سطح مكتب (Electron + SQLite)

### 1.3 الفوائد الرئيسية للتحول
1. **استقلالية كاملة:** يعمل بدون متصفح أو إنترنت
2. **أداء فائق:** SQLite أسرع بـ 10x من localStorage
3. **أمان محسّن:** بيانات مشفرة محلياً
4. **قابلية توسع:** يمكنه التعامل مع ملايين السجلات
